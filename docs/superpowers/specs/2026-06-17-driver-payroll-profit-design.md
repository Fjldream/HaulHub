# 司机工资与利润分析设计

## 背景

当前利润统计按已完成趟次收入、趟次费用和车辆维修费用计算利润。业务上还需要每月给司机发工资，并把工资作为经营支出计入月利润和年利润。司机工资既可能是固定月薪，也可能按趟次计薪，还会出现奖金、补贴、扣款和调整。

本设计把司机工资作为独立的月度成本模块接入系统，同时升级利润统计为更清晰的经营分析中心。

## 目标

- 管理员可以按司机和工资月份录入工资流水。
- 工资按“工资月份”归属利润，不按录入日期或实际发放日期归属利润。
- 支持固定工资、趟次工资、奖金补贴、扣款调整和其他类型。
- 支持按司机和月份查询计薪趟次数，主司机趟次和协同司机趟次都计入。
- 利润统计在月度和年度口径中扣除司机工资，并合理展示工资成本。
- 不影响现有趟次、维修、补录账单、车辆、司机管理和 App 端现有功能。

## 非目标

- 第一期不做工资自动审批流。
- 第一期不做司机端查看个人工资。
- 第一期不强制把工资分摊到每一台车或每一条线路。
- 第一期 App 管理员端不录入工资，只展示已计入工资后的利润结果。

## 核算规则

### 工资归属

每条工资记录必须选择 `工资月份`，格式为 `YYYY-MM`。例如选择 `2026-06`，则该工资计入 2026 年 6 月利润，也计入 2026 年年度利润。

`发放日期` 只用于查账和备注，不决定利润归属。

### 工资类型

工资流水支持以下类型：

- 固定工资
- 趟次工资
- 奖金/补贴
- 扣款/调整
- 其他

同一个司机同一个月份允许多条工资记录，因为可能同时存在固定工资、趟次工资、奖金和扣款。金额允许为负数，用于扣款和调账。

### 趟次计薪

按司机和工资月份查询计薪趟次时：

- 主司机完成趟次计入。
- 协同司机参与趟次也计入。
- 默认计薪趟次数 = 主司机完成趟次 + 协同参与趟次。
- 工资录入时可以引用默认计薪趟次数，也允许管理员手动修改计薪趟次数和最终金额。

只统计已完成趟次。撤销、待出车、进行中、已提交、审核中等未完成趟次不进入计薪趟次。

## 数据模型

新增 `DriverPayroll` 表：

- `id`
- `teamId`
- `driverId`
- `salaryMonth`：工资月份，建议存为 `YYYY-MM` 字符串，便于 SQLite 查询和表单处理。
- `type`：工资类型。
- `amount`：金额，Decimal，可正可负。
- `tripCount`：计薪趟次数，可空；趟次工资时建议填写。
- `unitAmount`：单趟金额，可空；趟次工资时建议填写。
- `paidAt`：实际发放日期，可空。
- `note`：备注。
- `createdBy`
- `createdAt`
- `updatedAt`

索引建议：

- `[teamId, salaryMonth]`
- `[teamId, driverId, salaryMonth]`
- `[teamId, type, salaryMonth]`

不做唯一约束，避免奖金、扣款和多次调账无法记录。

## API 设计

### 工资记录

- `GET /admin/driver-payrolls`
  - 查询参数：`month`、`driverId`、`type`、`q`、`page`、`pageSize`
  - 返回工资流水、司机信息、创建人信息和汇总金额。

- `POST /admin/driver-payrolls`
  - 创建工资记录。
  - 校验司机属于当前团队且角色为司机。
  - 校验工资月份格式为 `YYYY-MM`。
  - 校验金额为合法数字。

- `POST /admin/driver-payrolls/:payrollId`
  - 编辑工资记录。
  - 保持团队隔离。

- `POST /admin/driver-payrolls/:payrollId/delete`
  - 删除工资记录。
  - 第一期采用硬删除；如果后续需要审计更强，可以改成作废状态。

### 趟次计薪查询

- `GET /admin/driver-payrolls/trip-count`
  - 查询参数：`month`、`driverId`
  - 返回：
    - 主司机完成趟次数
    - 协同司机参与趟次数
    - 合计计薪趟次数
    - 趟次明细列表

### 利润统计

扩展 `GET /admin/reports/profit`：

- summary 增加：
  - `driverPayrollTotal`
  - `expenseTotal = tripExpenseTotal + maintenanceExpenseTotal + driverPayrollTotal`
  - `profitTotal = actualFreightTotal - expenseTotal`
  - `profitRate`

- byPeriod 增加：
  - `driverPayrollTotal`
  - `totalExpense`
  - `profitTotal`

- byExpenseType 或新增支出结构中把“司机工资”作为一级支出项展示。

工资只进入月度和年度口径。周度利润继续展示趟次费用和维修费用，并在 UI 上提示“司机工资按月归属，不计入周度统计”。

## Web 页面设计

### 工资记录

页面结构：

- 顶部筛选：工资月份、司机、工资类型、关键词。
- 摘要卡片：当月工资总额、固定工资、趟次工资、奖金补贴、扣款调整。
- 表格：司机、工资月份、类型、金额、计薪趟次、单趟金额、发放日期、备注、操作。
- 新增/编辑弹窗或页面：选择司机、工资月份、类型、金额、计薪趟次、单趟金额、发放日期、备注。

选择司机和月份后，表单内显示该司机当月计薪趟次：

- 主司机趟次
- 协同趟次
- 合计

选择“趟次工资”时：

- 默认把计薪趟次数填为合计趟次。
- 输入单趟金额后展示建议金额。
- 管理员可以修改最终金额。

### 趟次计薪查询

页面结构：

- 筛选：工资月份、司机。
- 概览卡片：主司机趟次、协同趟次、合计计薪趟次。
- 明细表：趟次号、完成日期、车辆、客户、路线、身份（主司机/协同司机）、实际运费。
- 快捷按钮：为该司机创建趟次工资记录。

### 利润总览

主指标：

- 实际运费
- 趟次费用
- 维修费用
- 司机工资
- 总支出
- 净利润
- 利润率

支出卡片分层展示：

```text
总支出
├─ 趟次费用
├─ 维修费用
└─ 司机工资
```

### 月度利润

按月表格：

- 月份
- 已完成趟次
- 实际运费
- 趟次费用
- 维修费用
- 司机工资
- 总支出
- 净利润
- 利润率

可以点击某月进入详情，查看该月工资成本和支出结构。

### 年度利润

按年汇总：

- 年度总收入
- 年度总支出
- 年度工资成本
- 年度净利润
- 年度利润率

下方展示 12 个月趋势，用于发现工资或维修费用异常月份。

### 工资成本

展示：

- 本月工资总额
- 工资占收入比例
- 每趟平均工资成本
- 固定工资、趟次工资、奖金补贴、扣款调整占比
- 司机工资排行

## App 管理员端

第一期不提供工资录入和编辑入口，避免移动端复杂表单影响发布风险。

App 管理员端利润统计需要适配新增字段：

- 月度和年度利润显示司机工资。
- 总支出包含司机工资。
- 周度页面提示工资按月归属，不计入周度统计。

## 权限和校验

- 仅管理员和财务角色可管理工资记录。
- 司机角色不可访问工资管理接口。
- 团队隔离必须覆盖工资记录、工资统计和趟次计薪查询。
- 禁用团队用户继续沿用现有登录限制。
- 金额输入使用现有 Decimal 校验策略，避免非法字符导致页面报错。
- 工资月份必须为 `YYYY-MM`。

## 审计和风险控制

工资涉及财务数据，建议写入审计日志：

- 创建工资
- 修改工资
- 删除工资

审计内容记录变更前后金额、月份、司机和类型。
